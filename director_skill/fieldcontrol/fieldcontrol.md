# Field Control

Query理解とSimulator理解の後、本番実験の前にGate 1、Gate 2、Gate 3を順番に確認する。失敗したGateより後へ進まない。Gate 1/2/3A/3B/3Cがすべて成立したとき、そのQueryのField Controlを完了とする。Field Controlの結果をQueryへの実験結果として数えない。

Gate 1とGate 2は`./system_fc.md`に従う。最初にそれぞれを完全に通す。次のQuery以降も省略せず順番に確認する。既に完全な通過記録があり、制御系とRuntime契約が同じ状態にあることを確認できる場合は簡略確認を使える。不一致、障害または判断不能があれば完全な確認へ戻る。

Gate 3は`./experiment_fc.md`に従う。対象の入力、実行、出力について3A、3B、3Cを判定する。新しいQueryでGate 3を再実行するか、既存の成立証拠を利用するかはDirectorが決める。既存証拠を使う場合も、現在の対象、入力、条件、方法、評価目的を実際に検証した範囲と照合する。照合できない部分は確認し直す。

Gate 3を確認するごとに、`./gate3_record/gate3-record-schema.md`に従って番号付きの記録を一つ残す。失敗、障害、判断不能とその切り分けも記録する。失敗後の再試行には前回からの変更点または新たに確かめる点を持たせる。確認に不要な仕組みやファイルを増やさない。
