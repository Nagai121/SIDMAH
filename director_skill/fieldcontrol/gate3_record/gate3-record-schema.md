# Gate 3 Record

Gate 3を確認するごとに、このディレクトリへ`gate3-record-<連番>.md`を一つ作る。連番は既存記録に続け、過去の記録を上書きしない。各記録には次を含める。

1. 対象のQueryとSimulator。参照した理解記録および既存のGate 3記録。
2. 今回確認する対象、入力、条件、方法と、既存証拠を再利用する範囲。
3. Gate 3Aの判定、入力の由来・内容・形式・受渡しを確認した方法と根拠。
4. Gate 3Bの判定、意図した処理の実行を確認した方法と根拠。
5. Gate 3Cの判定、出力と解析方法を確認した方法と根拠。
6. 障害、異常、判断不能、切り分け、再試行時の変更点。
7. Field Controlの通過判断と、その判断が有効な範囲。

未実施や既存証拠の再利用は、その理由と適用範囲を記す。確認できなかった事項を成立済みとして記録しない。
