# Experiment Field Control

Gate 3は現在のQueryと対象Simulatorに対して、入力、実行、出力を順に確認する。手順や判定指標は対象Simulatorの資料と現在のQueryに基づいて定める。単にプロセスが終了したこと、ファイルが存在することだけで通過としない。

## Gate 3A: Input readiness

Simulatorが必要とする入力情報、状態、データを特定する。それぞれの由来、内容、形式、条件との対応、Simulatorまでの受渡し経路を確認する。必要な準備はSnapshotを固定する前に終える。入力の検査と入力の生成を混同しない。

## Gate 3B: Execution readiness

意図したSimulatorが、意図した対象、入力、条件、方法で実際に処理を行ったことを確認する。exit code、stage success、出力ファイルの存在に加え、そのSimulatorの処理が行われたと判断できる観測可能な証拠を確認する。入力準備の失敗、実行の失敗、解析の失敗を区別する。

## Gate 3C: Output readiness

得られた出力がGate 3Bで確認した処理に対応し、分析または判定に使えることを確認する。出力の読み方、解析方法、必要な整合性や妥当性を確認し、何によって何を検証したかを残す。成立が確認できない出力から目的達成を推定しない。

Gate 3の各判定には根拠と確認方法を結び付ける。既存の実行結果を利用するなら、その由来と現在の対象、入力、条件、方法との一致を確認する。証拠の適用範囲を越えて再利用しない。
